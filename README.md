## 开源创新思维 · 作业1 摘要

- **被检项目**：Apache Maven 3.9.9 官方源码包（Apache 软件基金会顶级项目，Apache-2.0）
- **检测工具**：Apache Creadur RAT 0.18（ASF 官方发布审计工具，文件级许可证头扫描）
- **检测结果**：共 2099 个文件，通过 1478 个（Apache-2.0 1477、MIT 1），标准文件未通过 548 个（Unknown 547、GPL-2.0 1）
- **结论要点**：548 个告警中 535 个（97.6%）位于 `src/test` 测试资源，属合理例外；生产代码的真实问题仅 4 个 `package-info.java`；`javax.annotation-api` 的许可证文本被误判为 GPL-2.0 属典型文本误报。与项目自带 `apache-rat-plugin` 排除清单交叉验证后，告警可收敛为「4 处真实例外 + 4 处误报 + 1 份排除清单」。
